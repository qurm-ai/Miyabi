# Архитектура (6-сабақ)
QuizAI — мұғалімдерге жергілікті AI (Ollama) көмегімен сабақ мәтінінен тест сұрақтарын автоматты құрастырып, студенттерге оны онлайн тапсыруға мүмкіндік беретін жүйе.

```mermaid
flowchart LR
    B["Браузер"] --> W["Frontend · Next.js"]
    W -->|/api сұраныстары| A["Backend · FastAPI"]
    A -->|SQL сұраулары| P[("PostgreSQL")]
    B -->|кіру / OIDC| K["Keycloak"]
    A -->|токенді тексеру (RS256)| K
    A -->|сабақ мәтінінен сұрақ генерациялау| O["Ollama (Llama 3)"]
```

## Компоненттер
| Компонент | Не істейді | Сабақ |
|---|---|---|
| Frontend (Next.js) | Мұғалімдерге тест жасау, сұрақтарды басқару және студенттерге тест тапсыру веб-интерфейсі | 16 |
| Backend (FastAPI) | Бизнес-логика, REST API бағыттау, рөлдерді тексеру және AI-мен байланыс орнату | 7-9 |
| PostgreSQL | Пайдаланушылар, тесттер, сұрақтар, жауап нұсқалары мен нәтижелерді сенімді сақтау | 8 |
| Keycloak | Пайдаланушыларды тіркеу, кіру және рөлдерді (teacher, student) басқару | 10 |
| Ollama | Жергілікті Llama 3 моделі арқылы сұрақтар мен жауап нұсқаларын генерациялау | 11 |
